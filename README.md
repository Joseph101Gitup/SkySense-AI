# SkySense AI

SkySense AI is an end-to-end intelligent weather sensing and prediction platform. By combining AI-driven cloud recognition and rain prediction models with IoT edge sensors and a real-time mobile application, SkySense AI provides hyper-local weather forecasting and monitoring.

## 🚀 Key Features
- **AI-Powered Predictions**: Machine learning models for cloud classification and rain prediction.
- **IoT & Sensor Integration**: Edge data collection using Raspberry Pi devices.
- **IoT Simulator**: A Python-based simulator for testing and validation without hardware.
- **Real-Time Android App**: Mobile client for field visualization and weather alerts.
- **Robust Backend**: Server-side processing, storage, and API layer.

## 📁 Repository Structure
- `01_Project_Management/`: Roadmaps, timeline, milestones, and progress tracking.
- `02_Research/`: Academic research papers, reference documents, and literature review.
- `03_AI_Model/`: Jupyter notebooks, training scripts, datasets, and saved models.
- `04_Python_IoT_Simulator/`: Virtual IoT sensor network simulator.
- `05_Backend/`: API service, database integrations, and core logic.
- `06_Android_App/`: Client application source code.
- `07_Raspberry_Pi/`: Deployment scripts and sensor integration code.
- `08_Dataset/`: Sensor logs and data caches.
- `09_Testing/`: Integration, unit, and system validation scripts.
- `10_Documentation/`: User guides, system architecture diagrams, and APIs.
- `11_Research_Paper/`: Drafts and assets for IEEE publication.
- `12_Thesis/`: University thesis document chapters.
