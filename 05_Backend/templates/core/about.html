About SKYsense AI

A computer vision and deep learning system for automated rainfall likelihood estimation from sky-facing cloud imagery.

Master's Thesis Project

Developed as a final-year graduate engineering project combining computer vision, meteorological data processing, and production web deployment.

Xception Transfer Learning

Harnesses Google's 36-layer depthwise separable convolutional neural network pre-trained on ImageNet, fine-tuned for optical cloud morphology.

Production Django Engine

Engineered with clean architectural separation: Django handles the web dashboard and REST API, communicating seamlessly with a dedicated inference singleton.

Scientific Disclosure & Scope of Classification

Initial exploratory notebooks within the project referenced 11 World Meteorological Organization (WMO) cloud genus categories (such as Cirrus, Cumulonimbus, Stratus, Nimbostratus). Rigorous dataset auditing established that the verified dataset partitions into 3 verified rainfall likelihood categories across 2,543 images:

  • 0: Low_to_Medium_Rain
    1,004 images (39.5%)
  • 1: Medium_to_Heavy_Rain
    624 images (24.5%)
  • 2: No_to_Low_Rain
    915 images (36.0%)

Consequently, SKYsense AI explicitly operates as a 3-class rainfall category classifier, preserving rigorous scientific integrity and transparent empirical evaluation.

System Architecture & Data Pipeline

01 / INGESTION

Optical Capture

JPG/PNG sky images uploaded through web portal or sent via REST API from edge weather stations.

02 / PREPROCESSING

Validation & Rescaling

Payload inspection (<15MB), RGB conversion, resizing to 256×256, and floating-point [0.0, 1.0] scaling.

03 / INFERENCE

Xception Neural Net

Cached singleton model evaluation via TensorFlow 2.19, generating class probabilities via Softmax.

04 / DISSEMINATION

Dashboard & Storage

Results recorded in SQLite database, rendered in interactive responsive UI with meteorological advisories.
